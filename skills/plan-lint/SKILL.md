# plan-lint

計画の各行が、PDCAエンジンが読み取れる形式
`番号. [タスク名] 内容 (タイプ: nlp/code)` になっているかを、
スクリプトで機械的に検証する。モデルの目視確認に頼らないこと。

## 手順

1. 検証したい計画テキストをスクリプト `scripts/run.py` の標準入力に渡す。
2. スクリプトは行ごとに OK / NG を返し、NG があれば終了コード 1 で終わる。
3. NG の行があれば、その行番号と理由を報告し、計画の作り直しを提案する。
4. WARN（粒度の警告）が出た行は、小さいモデルで実行するにはタスクが
   大きすぎる疑いがある。説明が40字を超えている、または複数の手順が
   1タスクに入っている場合に警告される。分割を提案すること。
