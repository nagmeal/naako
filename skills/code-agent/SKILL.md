# code-agent

コーディングエージェント（Claude Code）に、実際のファイル編集を伴う
作業を委譲する。作業場所は、なあこが置かれているプロジェクトのルート。

## 手順

1. タスク本文を、そのままコーディングエージェントへの指示として
   スクリプト `scripts/run.py` の標準入力に渡す。
2. 1タスク＝1つの変更に絞る。複数ファイルにまたがる大きな変更は、
   計画の段階でタスクを分けること。
3. エージェントは数分間、自律的に編集とコマンド実行を行う。
   結果として「実施内容の要約＋ターン数・コスト」が返る。
4. エージェントは git コミットをしない。変更の取り込みは人間側で行う。
5. 失敗が返ったら、同じ指示をそのまま再実行しない。指示を小さく
   分け直してから再委譲すること。
