# web-search

DuckDuckGo Lite で Web 検索し、上位5件の「タイトル＋URL＋要約1行」を返す。
1タスクでは1つの問いだけを検索する。検索→ページを開く→要約、を
1タスクに詰め込まないこと。

## 手順

1. 検索したい問い（キーワード）をスクリプト `scripts/run.py` の標準入力に渡す。
2. スクリプトは上位5件を番号付きで返す。
3. 結果は検索スニペットであり、確定した事実として扱わない。
   報告や要約に使うときは、必ず出典のURLを添えること。
4. 特定のページの中身まで読みたい場合は、このスキルの仕事ではない。
   別のタスクとして扱うこと。
