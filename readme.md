# なあこ (Naako)

なあこは、ローカル LLM (Ollama) を活用した自己進化型 AI エージェントです。
メインエージェント「なあこ」が司令塔となり、必要に応じて専門的なサブエージェントを使い分けることで高度なタスクを遂行します。また、自分自身のコードを分析し、自律的に機能を拡張する能力を持っています。

## プロジェクトの目的
本プロジェクトの目的は、「AIが自ら自身の能力を定義し、実装し、検証することで、人間による直接的なコード修正なしに進化し続けるシステム」を構築することです。
具体的には、LLMによるコード生成能力と、テストコードによる自動検証を組み合わせることで、自律的な機能改善と拡張が可能なエージェントの実現を目指しています。

## 特徴

- **ハイブリッド・エージェント構造**: メインエージェントがユーザーの意図を解釈し、最適なサブエージェントを選択・制御します。
- **自律進化 (Self-Evolution)**: `/analyze` → `/plan` → `/evolve` のサイクルを通じて、自身のソースコードを書き換え、新しい機能を追加できます。
- **完全自律モード**: `/evolve-auto` コマンドにより、「分析・計画・実装・検証」のサイクルを自動で回し、目標達成まで自律的に進化します。

## 前提条件

- Python 3.10+
- [Ollama](https://ollama.com/) がインストールされ、起動していること
- 以下のモデルが利用可能であること（`settings.py` で変更可能）:
  - `gemma4:e4b` (メイン/サブエージェント用)
  - `gemma4:e2b` (軽量モデル)

```bash
ollama pull gemma4:e4b
ollama pull gemma4:e2b
```

## セットアップ

```bash
pip install ollama
```

## 実行方法

プロジェクトのルートディレクトリで以下を実行します。

```bash
python main.py
```

起動後、対話形式で操作できます。終了するには `/bye` と入力してください。

## 使い方

### 1. 基本的な会話
普通に話しかけると、なあこが回答します。

### 2. サブエージェントの指定
プロンプトの先頭に `[エージェント名]` を付けることで、特定の専門エージェントに処理を依頼できます。
- 例: `[coder] Pythonで効率的なソートアルゴリズムを実装して`
- 利用可能なエージェント: `coder`, `philosopher`, `researcher` など（`/add-agent` で追加可能）

### 3. 特殊コマンド

| コマンド | 説明 | 例 |
| :--- | :--- | :--- |
| `/subko [enable\|disable]` | サブエージェントの利用を切り替えます。 | `/subko disable` |
| `/set パス 値` | 設定ファイル (`settings.py`) の値を動的に変更します。 | `/set main.model "gemma4:e2b"` |
| `/add-agent 名前 プロンプト` | 新しい専門サブエージェントを追加します。 | `/add-agent poet "あなたは詩人です..."` |
| `/inject "旧コード" "新コード"` | 自身のコードの一部を直接書き換えます。 | `/inject "print('hello')" "print('hi')"` |
| `/analyze` | 現状のコードとロードマップを分析し、次の一手を提案します。 | `/analyze` |
| `/plan "内容"` | 提案された機能をロードマップ (`tasks/.../Roadmap.md`) に追加します。 | `/plan "記憶機能の実装: 過去の会話を保存する"` |
| `/evolve "テストファイル" "目標"` | 特定のテストをパスするように自律的にコードを修正します。 | `/evolve "test_evolve.py" "記憶機能の追加"` |
| `/evolve-auto` | 分析・計画・実装のサイクルを自動で繰り返し、自律進化します。 | `/evolve-auto` |
| `/bye` | プログラムを終了します。 | `/bye` |

## 内部構造

- `main.py`: エージェントのメインループとコマンド処理。
- `settings.py`: モデル設定、システムプロンプト、メッセージ定義の管理。
- `rewriter.py`: コードの検索・置換やテスト実行など、自己書き換えのためのユーティリティ。
- `tasks/`: 実装すべき機能のロードマップを管理。
