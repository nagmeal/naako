# なあこ

ローカル LLM（Ollama）を呼び出す AI エージェントです。メインエージェント「なあこ」が、専門的なサブエージェントを使い分けることで高度な回答を実現します。

## 前提条件

- Python 3
- [Ollama](https://ollama.com/) がインストールされ、起動していること
- モデル `gemma4:e4b` および `gemma4:e2b` が利用できること

```bash
ollama pull gemma4:e4b
ollama pull gemma4:e2b
```

## セットアップ

```bash
pip install ollama
```

## 実行方法

プロジェクトのルートで次を実行します。

```bash
python main.py
```

起動すると入力待ちになります。終了するには `/bye` と入力してください。

## 使い方

### 基本的な会話
普通に話しかけると、なあこが回答します。

### サブエージェントの利用
プロンプトの先頭に `[エージェント名]` を付けることで、特定の専門エージェントに処理を依頼できます。
（例：`[coder] Pythonで素数を判定する関数を書いて`）

- **利用可能なエージェント例**: `coder`, `philosopher`, `researcher`, `default`

### コマンド
- `/subko`: サブエージェントの有効/無効を切り替えます（無効にすると、なあこが直接回答します）。
- `/set パス 値`: 設定を動的に変更します（例：`/set main.system_prompt "新しいプロンプト"`）。
- `/add-agent 名前 プロンプト`: 新しいサブエージェントを追加します。
- `/bye`: プログラムを終了します。
