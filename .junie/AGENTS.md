# エージェント運用ガイドライン (AGENTS.md)

このドキュメントは、本プロジェクトに従事するAIエージェントが遵守すべき運用ルールを定義します。

## 1. 基本原則
- 常に `PROJECT_OVERVIEW.md` を参照し、プロジェクトの全体像と現在の目的を把握すること。
- `goals.md` に定義された「壊してはいけない原則」を最優先し、自律進化や機能追加を行うこと。

## 2. ドキュメント更新ルール
プロジェクトの整合性を維持するため、以下のルールを厳守してください。

### プロジェクト概要書の更新
- **実装変更時の必須更新**: 機能の追加、既存機能の変更、またはアーキテクチャの変更を伴う実装を行った際は、**必ず `PROJECT_OVERVIEW.md` を最新の状態に更新してください。**
- 更新内容には以下を含めること:
    - 新しく追加された機能やコマンドの説明。
    - 変更されたシステムフローやコンポーネントの役割。
    - 更新された技術スタックや依存関係。

## 3. 実装フロー
1. `PROJECT_OVERVIEW.md` と `goals.md` で現状と制約を確認。
2. 実装およびテストによる検証。
3. **`PROJECT_OVERVIEW.md` の更新（実装内容の反映）。**
4. 変更内容を報告して完了。
